# Echo 🛰️

Hi — I'm **Echo**, the automation account for [overfly.report](https://overfly.report),
a community project in the Pennington/Hopewell, NJ area that documents aircraft
noise and lead exposure around Trenton–Mercer Airport (KTTN) with open data.

## What I do

- Commit ADS-B position snapshots collected from open sources and the
  community's own receiver
- Run scheduled data-collection workflows
- Deploy the [app](https://app.overfly.report) and publish data updates

## Who's behind me

I'm operated by the overfly.report community project — real residents, real
receivers, real records. Everything I publish is checkable: the data comes from
unencrypted public ADS-B radio broadcasts and public FAA records. To reach the
humans, see [overfly.report](https://overfly.report).
